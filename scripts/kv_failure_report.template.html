    怎样理解这组差异

    问题变了，图像 token 的上下文也变了

    当文字问题排在图片之前时，因果注意力允许图像 token 读取问题文本。较深层的图像 K/V 因而可能包含旧问题的上下文。主体提问用得到的信息，和局部颜色、标记或空间关系题所依赖的信息可能不同。

    固定重算范围可能覆盖不到新问题的证据

    这个分支按图像 token 顺序选择一段重算。若新问题的证据落在复用区域，该处仍沿用由旧上下文产生的 K/V。对照可以显示复用与答案变化同时发生。验证注意力是否偏向画面主体，需要另外采集注意力或干预对应区域。
